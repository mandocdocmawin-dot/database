# Student Database (Step-by-Step)

This folder contains the **Student** database setup for Laravel using:

- `app/Models/Student.php`
- `database/migrations/2026_02_14_004951_create_students_table.php`
- `database/factories/StudentFactory.php`
- `database/seeders/StudentSeeder.php`

## Step 1: Student Model (`app/Models/Student.php`)

- The `Student` model represents the `students` table.
- `HasFactory` is enabled so you can use `Student::factory()`.
- `$fillable` defines which attributes can be mass-assigned:
  - `student_id`, `first_name`, `last_name`, `email`, `password`, `course`, `year_level`

## Step 2: Migration (`database/migrations/2026_02_14_004951_create_students_table.php`)

Running the migration creates the `students` table with:

- `uuid`
- `student_id` (unique)
- `first_name` (50)
- `last_name` (50)
- `email` (unique)
- `password`
- `year_level` (stored as `year`)
- `course` (100)
- `timestamps`

## Step 3: Factory (`database/factories/StudentFactory.php`)

The factory generates fake student records:

- `uuid`: generated using `Str::uuid()`
- `student_id`: formatted as `STU####` (example: `STU0007`)
- `first_name`, `last_name`, `email`: generated by Faker (email is unique)
- `password`: generated by Faker
- `course`: random from:
  - `BS Computer Science`
  - `BS Information Technology`
  - `BS Information System`
- `year_level`: random from `1st`, `2nd`, `3rd`, `4th`

## Step 4: Seeder (`database/seeders/StudentSeeder.php`)

The seeder inserts sample data using the factory:

- `Student::factory(10)->create();`

This creates **10** student rows in the `students` table.

## Step 5: Run Migration and Seeder

### A) Run migration

```bash
php artisan migrate
```

### B) Run only the Student seeder

```bash
php artisan db:seed --class=StudentSeeder
```

### C) Fresh migration + seed (reset database)

```bash
php artisan migrate:fresh --seed
```

## Note

The migration defines `year_level` as a `year`, but the factory generates values like `1st`, `2nd`, `3rd`, `4th`. If your seeding fails, update either:

- the migration column type (to string/enum), or
- the factory values (to actual years like `2024`, `2025`, etc.).
